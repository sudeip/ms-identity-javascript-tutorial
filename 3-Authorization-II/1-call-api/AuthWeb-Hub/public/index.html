🔑 AuthWeb Hub

AuthWeb Hub is the only BlueFlames app with real Entra ID configuration — one client ID, one tenant, one map of which spoke app needs which scope (authConfig.js). Titan, Phoenix and Falcon hold none of that themselves; they pass their small app id here and get a token back. Tokens live in sessionStorage here only (cleared when the tab closes) — Sign-out (End Shift) clears this session and signs out of Entra ID itself, which every spoke's own sign-out also routes through.
